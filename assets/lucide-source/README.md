# Lucide icons

These SVG icons are from Lucide v1.62.0, downloaded from the official repository:
https://github.com/lucide-icons/lucide/tree/1.62.0/icons

License notices are included in `LICENSE` (ISC for Lucide, with the MIT notice
for icons derived from Feather). `main.py` recolors the SVG stroke at render
time for the active application theme. The checkbox and numeric-input variants
in `../lucide-theme/` are recolored copies of Lucide's `check`, `chevron-up`,
and `chevron-down` icons.
